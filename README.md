# EFAS Vault Landing Page

EFAS Vault is a user-friendly, secure and responsive web based digital vault interface for storing and managing digital assets like files, notes, links, media and audio.

Project Structure

my-project/
  ├── index.html
 
  ├── css/
 
  │   ├── bootstrap.min.css

  │   └── custom.css

  ├── js/

  │   ├── bootstrap.bundle.min.js

  │   └── custom.js

  ├── img/

  │   └── (all images used in the project)

Features

- Responsive design using Bootstrap 5
- Encryption of login interface (UI)
- Showcase cards with hover effects
- Interactive mobile app prototype UI
- Modal information section
- Organized folder structure
- Custom theme styling (dark UI)

Technologies Used

- HTML5
- CSS3
- Bootstrap 5
- JavaScript (Vanilla JS)

Notes

- No CDN used, instead it is installed locally.
- All assets are well delivered into correct folders
